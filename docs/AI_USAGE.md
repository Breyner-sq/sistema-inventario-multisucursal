# Uso de Inteligencia Artificial

## 1. Objetivo

Este documento registra de forma transparente cómo se utilizan herramientas de inteligencia artificial durante el desarrollo.

El objetivo es demostrar:

- dirección humana;
- criterio técnico;
- revisión;
- validación;
- ajustes manuales;
- decisiones aceptadas;
- propuestas rechazadas.

La IA funciona como herramienta de asistencia y no como fuente automática de verdad.

## 2. Herramientas

### ChatGPT

Utilizado inicialmente para:

- interpretar la prueba;
- analizar alternativas tecnológicas;
- seleccionar stack;
- analizar arquitectura;
- diseñar estrategia de prompts;
- preparar documentación inicial.

### Claude

Será la herramienta principal durante el desarrollo para:

- análisis de requisitos;
- arquitectura;
- implementación;
- pruebas;
- revisión de código;
- documentación;
- auditoría.

## 3. Metodología

No se utilizarán instrucciones como:

> Haz todo el sistema.

El desarrollo seguirá:
